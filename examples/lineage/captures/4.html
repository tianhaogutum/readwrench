A practical backup routine

Begin with an inventory of the files you cannot recreate. Include family photographs, research notes, account recovery instructions, and the documents that explain how your work is organized. Keep a copy of this inventory outside your primary computer.

Store a second copy on a different physical device. A spare disk beside the laptop protects against a failed drive, but a fire or theft can still remove both copies. Choose a second location that remains accessible during a disruption.

After each software upgrade, restore a small sample using a clean account. This catches missing dependencies and permission problems that a normal file listing cannot reveal. Record the result beside the capture log.

Test one restore every month. Write down the tools and passwords you needed, and check that the restored files actually open. Recovery instructions are useful only if someone can follow them without the original computer.

Keep each backup for ninety days before rotating it out. Name the archives consistently so that you can identify a capture without relying on the filesystem modification date. A copied file can receive a new date while containing old information.
